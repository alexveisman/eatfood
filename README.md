# Домашняя кухня & выпечка

Сайт-каталог домашней кухни: меню с фотографиями, поиск по блюдам и начинкам,
заказ через WhatsApp и панель владельца для правки меню без программиста.

Стек: React 19 + TypeScript + Vite + Tailwind CSS 4, данные — Firebase Firestore,
фотографии — Firebase Storage, публикация — Vercel.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:3000
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запуск для разработки |
| `npm run build` | Сборка в папку `dist` (перед сборкой пересобирает фото) |
| `npm run preview` | Просмотр собранной версии |
| `npm run lint` | Проверка типов TypeScript |
| `npm run images` | Пересборка вариантов фотографий |

## Панель владельца

`ваш-сайт/#admin` — вход по PIN (стандартный `2026`, меняется на вкладке «Настройки»).

Через панель меняются фотографии, цены, описания, порядок блюд и состав меню.

## Как устроены фотографии

В сборке фотографий нет. Все снимки владелец загружает через панель: они сжимаются
в браузере, уходят в Firebase Storage и подставляются в меню обычной ссылкой.
У блюда без фотографии выводится заглушка.

Если фотографию когда-нибудь понадобится вшить прямо в сборку (например, для
оформления страницы), положите файл в `src/assets/images/source/` и выполните
`npm run images`: скрипт сделает варианты 400/800/1200px в WebP, запасной JPEG и
размытый плейсхолдер, а затем сгенерирует `src/assets/images/manifest.ts`, откуда
снимок подставляется в `src/data/menuData.ts`. Без этой папки шаг просто пропускается.

Компонент `SmartImage` в обоих случаях резервирует место под картинку, показывает
заглушку во время загрузки и выбирает подходящий размер из `srcSet`.

## Структура

```
scripts/optimize-images.mjs   Генератор адаптивных изображений (если фото вшиты)
src/components/               Компоненты витрины
src/components/admin/         Панель владельца
src/services/                 Работа с данными и загрузка фото
src/utils/                    Сжатие изображений, IndexedDB, доступ, i18n
src/data/menuData.ts          Меню по умолчанию
firestore.rules               Правила доступа к базе
storage.rules                 Правила доступа к хранилищу фото
```

## Настройка и публикация

Пошаговая инструкция — [docs/НАСТРОЙКА.md](docs/НАСТРОЙКА.md): развёртывание на
Vercel, настройка Firebase и включение защиты базы.

> **Важно:** пока правила Firestore не опубликованы (шаг 3 инструкции), панель
> сохраняет изменения только в браузере владельца — посетители их не увидят.
