# Сюда кладём исходные фото блюд

Положите сюда обычный файл фотографии — прямо с телефона, без обработки.
Всё остальное сделает сборка: она сама уменьшит фото, создаст версии для
телефона и для десктопа и подложит размытую заглушку на время загрузки.

## Как назвать файл

Имя файла = id блюда из `src/data/menuData.ts`. Например:

| Блюдо                | Имя файла                  |
|----------------------|----------------------------|
| Оливье               | `salad-olivier.jpg`        |
| Винегрет             | `salad-vinegret.jpg`       |
| Сельдь под шубой     | `salad-herring-coat.jpg`   |
| Пельмени             | `pelmeni-homemade.jpg`     |
| Голубцы              | `golubtsy-homemade.jpg`    |

Подходят форматы `.jpg`, `.jpeg`, `.png`, `.webp`.

## Что дальше

Сборка на Vercel запускает `npm run images` автоматически, так что после
загрузки файла в этот каталог фото появится на сайте само.

## Важно про чужие фото

Загружайте только свои снимки. Фото из интернета (особенно с водяным
знаком чужого сайта) использовать нельзя — это чужая собственность.
