# Сюда кладём фотографии для сайта

Положите сюда обычный файл фотографии — прямо с телефона, без обработки.
Всё остальное сделает сборка: уменьшит фото, создаст версии для телефона и
для десктопа и подложит размытую заглушку на время загрузки.

**Правку кода это не требует.** Всё решает имя файла.

## Фото блюда

Имя файла = id блюда из `src/data/menuData.ts`:

| Блюдо            | Имя файла                  |
|------------------|----------------------------|
| Оливье           | `salad-olivier.jpg`        |
| Винегрет         | `salad-vinegret.jpg`       |
| Сельдь под шубой | `salad-herring-coat.jpg`   |
| Пирожки          | `pirozhki-homemade.jpg`    |
| Пельмени         | `pelmeni-homemade.jpg`     |
| Голубцы          | `golubtsy-homemade.jpg`    |
| Блины            | `pancakes-blini.jpg`       |
| Вареники         | `vareniki-handmade.jpg`    |
| Сырники          | `syrniki.jpg`              |
| Осетинский пирог | `ossetian-pie.jpg`         |
| Плацинды         | `placinte-moldavian.jpg`   |
| Ватрушки         | `vatrushki-cottage-cheese.jpg` |
| Синнабоны        | `cinnamon-rolls.jpg`       |

Такое фото встаёт в карточку блюда и заодно попадает в ленту внизу страницы.

## Фото только для галереи

Если снимок не относится к блюду из меню (общий вид стола, процесс, разрез),
назовите файл `gallery-` и дальше как угодно латиницей:

    gallery-draniki.jpg
    gallery-pirozhki-box.jpg

Он попадёт только в ленту фотографий внизу страницы.

Подписи к таким фото (их читает голосовой помощник для незрячих) задаются в
`src/assets/images/builtInPhotos.ts`. Без подписи фото тоже показывается —
просто с общим текстом.

## Форматы

`.jpg`, `.jpeg`, `.png`, `.webp`. Размер и вес не важны — сжатие автоматическое.

## Важно про чужие фото

Загружайте только свои снимки. Фото из интернета — особенно с водяным знаком
чужого сайта — использовать нельзя, это чужая собственность.
